# واجد

تطبيق التسيير ديال حوانت إصلاح التيليفونات (بركان).

- **التيكيات:** تسلم ← فالإصلاح ← واجد ← تسلم للكليان، مع ميساجات WhatsApp
- **القطعة إجبارية قبل "واجد":** من الستوك (كتنقص بوحدها) / من عند صاحبي (كتزاد فالكريدي) / شريتها / بلا قطعة
- **الضمانة**، تذكير التيليفونات اللي ما رجعوش، العد ديال السيمانة
- **الحسابات:** الربح، ثمن القطع، المصاريف، رسم ديال 8 سيمانات
- **الكريدي** بين الحوانت
- **سجل التيليفونات المستعملة:** IMEI (مع التحقق) + البطاقة ديال البائع والمشتري
- نسخة احتياطية (تصدير / استيراد JSON)

النسخة 1: فيشي HTML واحد، والبيانات فـ `localStorage`. المرحلة الجاية: Supabase (حساب لكل حانوت).

## النشر

`.github/workflows/pages.yml` كينشر على GitHub Pages مع كل push لـ `main`.
مرة وحدة: Settings ← Pages ← Source: **GitHub Actions**.

## Escucha Palabras (`es/`)

`es/index.html`: كتب كلمة بالإسبانية (بحال *gracias*) وكيطلعو ليك فيديوهات ديال ناس كيقولوها، والفيديو كيبدا فالثانية اللي تقالت فيها.
المحرك ديالنا: ما كيعتمدش على YouGlish.

- `es/corpus/*.tsv`: النص ديال كل فيديو مع الوقت (فيديو واحد = فيشي واحد).
- `scripts/import_transcripts.py`: كيحوّل النتيجة ديال Firecrawl (`youtube-com/videos/video_transcript`) لـ `.tsv`.
- `scripts/build_corpus.py`: كيجمع كاع الفيشيات فـ `es/corpus.js` (خاصك تعاودو كل مرة تزيد فيديو).
